# RGB Core Changelog

## Tondi Native Fork

- Tondi/P2MR is the active publication target.
- RGB metadata must remain off-chain and must not be serialized into Tondi
  payloads, signature scripts, witness data, or Annex-style carriers.
- Legacy chain-specific commitment examples were removed from the active
  RGB-on-Tondi workflow surface.

Historical upstream release notes are intentionally omitted from this fork-level
changelog to avoid presenting deprecated publication paths as supported runtime
behavior.
